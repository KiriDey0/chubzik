# Чубзик

Нативный островок для macOS 14 и новее на Apple silicon. Окна и персонаж работают на AppKit и Core Animation. Панели написаны на SwiftUI.

## Установка

Скачай `Chubzik-<версия>-macOS-arm64.zip` из [GitHub Releases](https://github.com/KiriDey0/chubzik/releases/latest), распакуй и перенеси `Чубзик.app` в «Программы». Для быстрого чата нужен установленный Codex CLI со входом в аккаунт.

Сборка подписана ad hoc. При первом запуске на другом Mac может потребоваться открыть «Системные настройки → Конфиденциальность и безопасность» и подтвердить запуск через «Всё равно открыть». [Инструкция Apple](https://support.apple.com/102445)

В релизе также есть архив исходников и SHA-256 для обоих файлов.

## Чёлка

Наведение на чёлку открывает компактный плеер. Клик по свободному месту или переход из другого раздела открывают полный плеер. Все развёрнутые разделы имеют общую высоту. Панель ждёт до секунды у края и сворачивается быстрее при удалении курсора. Возврат курсора во время сворачивания раскрывает текущую панель.

Нажатие на квадратную иконку в верхней строке открывает её раздел. Горизонтальный свайп двумя пальцами перелистывает разделы по одному.

Булавка в шапке закрепляет панель. Нажми её ещё раз, чтобы вернуть автозакрытие. `Esc` при активной панели закрывает её и снимает закрепление.

Ползунки справа сверху и пункт «Настройки…» в строке меню открывают отдельное окно. В нём можно выбрать стартовый раздел и глобальную горячую клавишу, отключить открытие при наведении, движение глаз, погоню за курсором при запросах Codex и системный Now Playing. Изменения сохраняются сразу. При повторном открытии в течение 25 секунд панель возвращает последний раздел.

Полка показывает файлы сеткой с системными значками и миниатюрами. Добавлять файлы можно с чёлки, из диалога выбора и из буфера обмена после фокусировки сетки. Стрелки перемещают выделение, Return открывает файл, Пробел показывает предпросмотр. С `⌘` или `⇧` можно выбрать несколько файлов для копирования, перетаскивания или передачи через меню «Поделиться». Backspace убирает ссылки с полки, «Отменить» возвращает их в течение восьми секунд.

В Finder **Быстрые действия → На полку** добавляет выбранные файлы и папки. Чубзик подхватывает значок у указателя, относит его к чёлке и возвращается домой. Панель остаётся свёрнутой, если была закрыта. Действие **На полку** также доступно в приложениях, которые передают выделенные файлы в меню «Службы». При установке на другой Mac скопируй `На полку.workflow` из `Чубзик.app/Contents/Resources` в `~/Library/Services`.

`⌘V` работает и на пустой полке. Через контекстное меню можно закрепить до четырёх файлов в начале сетки. `⌘F` открывает поиск по имени, Return открывает первое совпадение.

**⌃⌥F** приносит последнюю завершённую загрузку ArDia Personal, **⌃⌥R** приносит файлы из последнего ответа Codex, в котором остались доступные локальные файлы. Чубзик подлетает, ставит карточку у указателя и возвращается. Карточку можно перетащить в письмо, переписку или другое окно. Стрелки переключают файлы из одного ответа, Esc закрывает карточку. Сочетания настраиваются в разделе «Файлы».

Когда уже открыт системный диалог «Открыть», эти сочетания выделяют файл прямо в нём. Если результатов несколько, сначала выбери нужный на карточке. Последнее подтверждение остаётся за тобой. **⌃⌥P** открывает в Finder рабочую папку активного диалога Codex. Сочетание можно сменить или отключить в «Файлах».

В «Файлах» можно включить карманы буфера на **⌃⌥V**. У указателя появятся восемь последних элементов. «Вся история» открывает поиск по локальным записям за последние 24 часа. Выбранный элемент можно вставить со своим исходным форматом. Изображение можно положить на полку или прикрепить к быстрому вопросу. Ограничения истории — 180 элементов, 128 МБ суммарно и 24 МБ на элемент. Выключение удаляет историю карманов.

В меню **Проверить чубзика** есть демонстрации любопытного взгляда, файла на полке, завершения таймера и запроса Codex. Приложение учитывает системное уменьшение движения.

Догонялки запускаются из меню Чубзика или кнопкой «Начать» в разделе «Общие» его настроек. Чубзик подкрадывается на разное расстояние и иногда делает ложный замах. Прыгает туда, где указатель был в момент рывка. Если поймает, потащит его на 0,7–2,5 секунды по прямой, дугой или змейкой. Движение мыши позволяет сопротивляться. `Esc`, переход в другое приложение или на другой рабочий стол сразу завершают игру.

## Быстрый чат

`⌥ Space` открывает поле у указателя. Enter отправляет вопрос и вложение. Пока чат открыт, `⌘⇧W` включает крестик. Подведи его к началу области, зажми кнопку и протяни рамку. При отпускании снимок появляется в поле ввода. Одиночный щелчок и сдвиг меньше 16 точек ничего не снимают. `Esc` отменяет выделение. Чтобы снять весь монитор, протяни рамку между его противоположными углами. Уже отправленный снимок можно снова приложить через меню его миниатюры. Для захвата macOS потребуется доступ к записи экрана.

`Esc` в чате сворачивает окно и сохраняет черновик. Ответ продолжает загружаться в фоне. Когда он готов, Чубзик подаёт сигнал, а `⌥ Space` снова открывает чат. Для отмены запроса есть кнопка «Остановить». Команда «Спросить Чубзика» в меню «Службы» macOS добавляет выделенный текст к вопросу. Этот фрагмент сохраняется вместе с черновиком, даже если сам вопрос ещё пустой.

Чат использует GPT-6 Luna · High через текущий вход Codex CLI. Соединение переиспользуется и обновляется при смене входа. Иконка диалогов на чёлке открывает локальную историю. На Mac сохраняются вопросы, ответы и текст черновиков. После перезапуска `⌥ Space` продолжает последний сохранённый черновик или открывает прерванный ответ. Его можно повторить вручную. Снимки остаются в памяти приложения. После перезапуска Чубзик помнит, что в черновике было вложение. Его можно прикрепить заново или убрать перед отправкой. Для повтора прерванного запроса со снимком прикрепи изображение заново.

В контекстном меню изображения на полке пункт «Спросить об этом» открывает чат с вложением. Черновик сохраняется. Если ответ ещё загружается, изображение добавляется в черновик следующего сообщения. Клик по входящим Codex открывает последний завершённый чат. Удержание кнопки показывает список входящих. Если Чубзик застал тебя за кликом или перетаскиванием, у чёлки появляется кнопка перехода к ответу.

В «Настройки → Общие → Когда ответ готов» мягкий режим дважды тянет указатель лапой. Чубзик выбирает сторону по положению указателя относительно чёлки и иногда заходит сверху. Средний режим добавляет паузу видео и кнопку «К ответу». В высоком режиме Чубзик ставит играющее видео на паузу, берёт указатель лапой и открывает завершившийся диалог Codex. Перед переходом он ещё раз проверяет воспроизведение, чтобы заметить видео, запущенное во время подлёта. Если состояние видео неизвестно, он подаёт сигнал и показывает кнопку «К ответу».

Чубзик сверяет заголовок открытого окна с уникальным названием диалога в локальном индексе Codex. После подтверждения он отмечает ответ прочитанным и ведёт указатель к полю ввода на том же экране. Для поиска поля используются доступность macOS и локальное распознавание окна при уже выданном доступе к записи экрана. Если несколько диалогов завершились вместе, Чубзик дважды дёргает указатель, а кнопка открывает список ответов. Видео в этом случае продолжает идти. Esc, клик и резкое движение мыши отменяют текущий жест.

Чубзик может поставить на паузу видео в активной вкладке и в «Картинке в картинке». В ArDia Personal всплывающее видео поддерживается и в фоновой вкладке, в том числе для плееров во фреймах того же origin. Для ArDia Personal без CDP в настройках Чубзика есть «Подключить ArDia без CDP». Разреши автоматизацию macOS и включи в ArDia **View → Developer → Allow JavaScript from Apple Events**. Если в ArDia уже запущен CDP на 127.0.0.1:9222, его можно использовать без Apple Events. Для других поддерживаемых браузеров используется доступность macOS. Когда нужный ролик нельзя однозначно определить, Чубзик ограничивается двумя рывками.

В среднем и высоком режимах переключатель «Возвращаться обратно» включает возврат после отправки следующего сообщения в том же диалоге Codex. Чубзик запоминает исходное окно, а в ArDia Personal с разрешённой автоматизацией — и вкладку. Если он сам поставил видео на паузу, оно продолжится при возврате, пока плеер доступен и позиция не менялась. Переключение из Codex вручную отменяет возврат. Переключатель изначально выключен.

Если календарь подключён, за пять минут до встречи со ссылкой у чёлки появляется «Войти». Кнопка остаётся до пяти минут после начала, если встреча ещё идёт. Если в это время доступны несколько встреч, кнопка открывает список с их названиями и временем начала.

## Сборка

```sh
./build.sh test
./build.sh
open '.build/Чубзик.app'
```

Требуется macOS с Xcode Command Line Tools. В `Resources` есть собранный MediaRemote Adapter и лицензия BSD-3-Clause. Исходники адаптера взяты из ревизии `14eed9389241d06e29f7326c19e9ebc6ac8a5f36`. Для постоянной локальной подписи один раз запусти `./setup-local-signing.sh`. Ключ хранится в пользовательской связке ключей macOS. Сборки на этом Mac используют один идентификатор подписи. Без этой настройки сборка подписывается ad hoc. [MediaRemote Adapter](https://github.com/ungive/mediaremote-adapter/tree/14eed9389241d06e29f7326c19e9ebc6ac8a5f36)

`./build.sh --ad-hoc` собирает приложение с подписью ad hoc на любой машине, независимо от настроенной локальной подписи. Исходник иконки находится в `Tools/make-icon.swift`.

## Данные и события

Полка, таймер, секундомер, список задач и заметка лежат в `~/Library/Application Support/Chubzik`. Полка хранит пути и файловые закладки macOS. Когда старый путь пропадает, полка может найти переименованный или перемещённый файл на том же диске. Погода и почасовой прогноз загружаются по кнопке через Open-Meteo. Сетка календаря доступна сразу. События из EventKit появляются после выдачи доступа.

Мосты «Лада» и ArDia передают состояние через локальные распределённые уведомления macOS. `local.kirill.chubzik.event` используется для состояния, `local.kirill.chubzik.command` для команд. Клиенты передают новое состояние после установления связи с островком. Сайт во вкладке прямого доступа к этому мосту не имеет. ArDia исключает вкладки инкогнито и приватные загрузки из прямого обмена.

Опциональный системный Now Playing слушает один поток событий. В macOS он реализован через MediaRemote Adapter и зависит от поведения приватного системного API. Команды воспроизведения запускаются по действию пользователя.

Сигналы Codex читают из входа хуков `UserPromptSubmit`, `PermissionRequest`, `Stop` и `SessionEnd`. Обработчик публикует тип события и ID чата. [Документация Codex Hooks](https://learn.chatgpt.com/docs/hooks)

```sh
python3 Tools/codex_hooks.py install '/абсолютный/путь/к/Чубзик.app'
python3 Tools/codex_hooks.py remove '/абсолютный/путь/к/Чубзик.app'
```

Удаление снимает только хуки, зарегистрированные этим путём. Codex может запросить доверие к новым хукам через `/hooks`.

## Локальная проверка

`Tests/ModelTests.swift` проверяет геометрию, дельты медиаданных, полку, очистку ссылок и расчёт времени. `Tests/MacSmoke.swift` проверяет реальные окна, реакции плеера на наведение и клик, закрытие панели, ввод заметки, перетаскивание и погоню. У автоматической проверки окон должны уже быть разрешения на запись экрана и отправку событий ввода.

```sh
.build/Чубзик.app/Contents/MacOS/Chubzik --fixture --show-panel
```

Тестовый источник можно листать и перематывать. В меню приложения есть сценарии Codex для проверки реакций. Для изоляции файлов в тесте можно задать `CHUBZIK_DATA_DIR`.
